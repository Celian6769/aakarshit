# Aakarshit Personal Website

A standalone static website inspired by the supplied visual references.

## Files

- index.html
- style.css
- script.js
- after-dark.mp3 (optional, add your own legally obtained/licensed copy)

## Open locally

Double-click `index.html` to open the site. No Node.js or build step is required.

## Music

The site includes a MUSIC / OFF control. It expects an audio file named `after-dark.mp3` beside `index.html`. The copyrighted recording is not included.

## Background audio
The website uses the uploaded `midnight-synthwave.mp3` track. Keep the audio file beside `index.html` when deploying.
